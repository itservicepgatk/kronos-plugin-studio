# KRONOS Guard & Moderation v1.0.0

Анти-грифер + полноценная система модерации для **Pumpkin 26.3** (`wasm32-wasip1`, Rust).

## Основные возможности

- **Наказания с иерархией рангов** (`/ban`, `/tempban`, `/ipban`, `/unban`, `/mute`, `/unmute`, `/warn`, `/unwarn`, `/warns`, `/kick`, `/history`) — младший модератор не может наказать старшего.
- **Авто-эскалация предупреждений**:
  - `2 варна` → авто-мут на `30m`
  - `3 варна` → авто-бан на `24h`
  - `5 варнов` → авто-бан на `7d`
- **Ваниш (`/vanish` / `/v`)**: полная невидимость от игроков ниже рангом, фейковые сообщения выхода/входа, тихое открытие сундуков без записи в лог, постоянный ActionBar-индикатор.
- **Проверка на читы (`/freeze <игрок>`)**: заморозка подозреваемого; если выйдет с сервера во время проверки — автоматический tempban на `7d`.
- **Чат-Гвард (Анти-Спам + Анти-Реклама + Анти-Капс + Фильтр мата)**:
  - блокирует IP-адреса, домены (включая обходы через пробелы/запятые/`(dot)`), ссылки `discord.gg`/`t.me` с белым списком своего домена (`kronosmc.ru`);
  - кулдаун, анти-дубликаты, защита от флуда (4 сообщения за 5с);
  - авто-мут после 3 нарушений с уведомлением персонала.
- **Компактный журнал блоков и сундуков (как CoreProtect)**:
  - `/co i` (или `/guard inspect`) — режим инспектора (выдаёт `minecraft:spyglass`): клик по блоку или сундуку показывает кто сломал/поставил/открыл/взял предмет и сколько времени назад;
  - `/co l r:10 t:1h u:Steve` — поиск действий в радиусе;
  - `/co rb r:15 t:30m u:Steve` — откат грифа (восстановление сломанных/взорванных блоков, очистка разлитой лавы/воды) + `/guard undo` для отмены.
- **5 Chest GUI-меню**: Главная панель Guard (`/guard`), Карточка игрока (`/guard player <ник>`), История наказаний, Очередь жалоб (`/report`), Просмотр журнала блока.
- **Чат персонала (`/sc`)** и **Атомарное автосохранение** (`*.tmp` → `rename`).

## Сборка в `.wasm`

```bash
rustup target add wasm32-wasip1
cargo test
cargo build --target wasm32-wasip1 --release
```

Готовый файл `target/wasm32-wasip1/release/kronos_guard.wasm` и `data/config.json` скопируйте в папку плагинов сервера Pumpkin 26.3.
