## Двойная ветка (Dual-Track) и Синхронизация

- Игрок может **одновременно** иметь купленный донат (например, `kronos`) и стафф-должность (например, `trainee` или `moder`): в табе и чате отображается должность стаффа, а все купленные лимиты домов/приватов сохраняются (`max(donate, staff)`).
- При любом изменении ранга плагин синхронизирует `host_set_player_rank` и обновляет общий файл `data/kronos_ranks_bridge.json`, который читают `kronos-essentials`, `kronos-regions` и `kronos-guard`.

## Команды

- `/donate` / `/ranks` — GUI-витрина всех 10 донат-рангов.
- `/staff` — GUI всех 9 должностей по 5 отделам + кто онлайн.
- `/staff online` — список онлайн-сотрудников по отделам.
- `/staff apply <анкета>` — подать заявку в Отдел Набора (HR).
- `/staff hr` / `/staff audit` — HR-панель заявок и журнал назначений.
- `/rank set <игрок> <ранг> [срок|perm]` — выдать ранг (с проверкой отдела и веса).
- `/rank remove <игрок> [staff|donate]` — снять стафф или донат.
- `/rank perm <игрок> <add|remove|check> <право>` — управление личными правами.
- `/rank suffix <текст|clear>` — кастомный суффикс (`emperor+`).
