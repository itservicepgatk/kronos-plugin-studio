## Архитектура Pumpkin 26.3 (`pumpkin-plugin-api`)

- **Нативный Таб-лист**: `player.set_tab_list_name`, сортировка по весу ранга через `player.set_tab_list_order(weight as i32)`, анимированный заголовок и подвал (`set_tab_list_header_footer`) с онлайном, пингом (`player.get_ping()`), отделом и магазином.
- **Форматирование чата и `/sc`**: `PlayerChatEvent` перехватывает и рассылает отформатированный `TextComponent` с префиксом, цветом ника, суффиксом и поддержкой `&`-кодов для VIP+ (и жирных/RGB-стилей для Immortal+). Команда `/sc` отправляет закрытый чат только онлайн-сотрудникам (`kronos-ranks:staff` или вес ранга `>= 100`).
- **Dual-Track и Кросс-плагинный мост**: игрок может одновременно иметь купленный донат и стафф-должность (`max(donate, staff)` для лимитов). При каждом изменении атомарно сохраняется `kronos_ranks.json` и экспортируется `kronos_ranks_bridge.json` для `kronos-essentials`, `kronos-regions` и `kronos-guard`.
- **Кросс-платформенные меню**: интерактивные кликабельные `TextComponent`-меню с hover-подсказками для Java (1.20.1–26.3) и нативные `SimpleForm` для Bedrock (`player.as_bedrock()`).

## Права (Permissions)

- `kronos-ranks:player` (`PermissionDefault::Allow`) — базовые команды `/donate`, `/ranks`, `/staff`, `/rank info`, `/rank list`, `/rank suffix`, `/staff apply`.
- `kronos-ranks:staff` (`PermissionDefault::Op(Level::Two)`) — доступ к стафф-чату `/sc`, `/staff hr`, `/staff audit`.
- `kronos-ranks:admin` (`PermissionDefault::Op(Level::Three)`) — административное управление рангами и правами.

## Команды

- `/donate` / `/ranks` — интерактивная витрина всех 10 донат-рангов с hover-описаниями и ценами.
- `/staff` — интерактивное меню всех 9 должностей по 5 отделам + кто сейчас онлайн.
- `/staff online` — список онлайн-сотрудников по отделам.
- `/staff apply <должность> <о_себе>` — подать заявку в Отдел Набора (HR).
- `/staff hr [accept <id> | reject <id>]` — HR-панель заявок с одобрением/отклонением в один клик.
- `/staff audit` — журнал назначений и изменений рангов.
- `/sc <сообщение>` / `/staffchat <сообщение>` — закрытый чат стаффа.
- `/rank set <игрок> <ранг> [срок|perm]` (алиас `/setrank`) — выдать ранг с проверкой отдела и веса (работает и из консоли).
- `/rank reset <игрок>` — полный сброс донат- и стафф-ранга игрока.
- `/rank remove <игрок> [staff|donate]` — снять только стафф-должность или донат.
- `/rank info [игрок]` — карточка Dual-Track профиля игрока и итоговых лимитов.
- `/rank list` — список всех 20 рангов с весами и кликабельной выдачей.
- `/rank perm <игрок> <add|remove|check> <право>` — управление личными правами (защита `*`, `kronos.*`, `kronos.ranks.*` для Owner/Console).
- `/rank suffix <текст|clear>` — кастомный суффикс (`emperor+`).
